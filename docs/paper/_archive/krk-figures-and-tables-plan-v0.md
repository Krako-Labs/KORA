## Table 1: Execution Paths

| Path | Meaning | Evidence Needed |
| --- | --- | --- |
| deterministic | Known logic or structured checks resolve the item. | Handler result and validation status. |
| cache | A valid cached result can be reused. | Cache key, cache validity, and policy status. |
| CPU | CPU-local execution is adequate. | Target metadata and workload shape. |
| provider | Provider-backed model execution is justified. | Provider route reason and policy status. |
| GPU | GPU-class execution is justified. | Workload shape, complexity, and bounded measurement status. |
| fallback | Preferred paths are unsafe, unavailable, invalid, or blocked. | Fallback class and rejected-path reason. |
