# KORA Core Alpha Claim Boundary v0

## Public Positioning

Allowed public positioning:

- KORA makes AI workloads routable.
- KRK is the KORA Routing Kernel.
- KRK is a deterministic-first execution routing kernel.
- KORA Core is the planned open-source AI workload execution layer.
- The current alpha focuses on routing and evidence reporting.
- Current commands such as `route`, `explain`, `benchmark`, and `report` are KRK alpha primitives.

## Bounded Benchmark Claim

Allowed bounded benchmark wording:

> In a reproducible 100-task deterministic-heavy benchmark workload, KORA-controlled execution avoided 80 of 100 simulated model invocations versus a naive direct baseline.

This wording is limited to the specific deterministic-heavy benchmark workload. It is not a production cost, customer savings, infrastructure savings, or broad superiority claim.

## Roadmap Language

Allowed roadmap language:

- KORA Core is planned to expand toward inspect, compare, run, report, doctor, workload specs, target registries, evidence reports, adapters, examples, and developer preview materials.
- Future surfaces should be labeled as planned, roadmap, future, or proposed until implemented.

## Prohibited Claims

Do not claim:

- production cost reduction.
- 10x savings.
- real API cost reduction proof.
- customer savings.
- infrastructure savings.
- broad workload superiority.
- replacement of vLLM, OpenRouter, LiteLLM, OpenAI, Claude, Gemini, or other systems.
- H100 superiority.
- production validation.

## Public/Private Boundary

Public docs must not include private resource details, private operating prompts, private repo paths, raw logs, credentials, or unsanitized internal artifacts.
