## Purpose

This registry separates supported claims from unsupported claims and future evidence requirements.

## Claim Categories

- Supported: backed by current public evidence.
- Allowed with caveats: true only within stated limits.
- Not supported: do not use in public positioning.
- Future evidence required: possible later, but not currently supported.
